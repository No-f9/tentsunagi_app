# 点つなぎ

見本と同じ形になるように点と点を線でつなぐ、3歳から使える点描写練習アプリ（iPad・指で操作）。

公開URL: https://no-f9.github.io/tentsunagi_app/

## できること

- **れんしゅう**：全50レベル。1問正解するごとにどうぶつスタンプが1つ増え、20個でレベルクリア
  - Lv1〜5：3×3（Lv4から斜め）
  - Lv6〜15：5×5（縦・横・斜め45度）
  - Lv16〜25：5×5（横2・縦1などの斜めも使う）
  - Lv26〜40：7×7
  - Lv41〜50：7×7の立体図形（直方体・階段）
- **3つのモード**：ふつう／さかさ（上下逆転）／かがみ（鏡絵）。さかさ・かがみは、ふつうのレベル5をクリアすると選べる
- **おさらい**：クリアしたレベルを選んで復習（進み具合は変わらない）
- **とっくん**：間違えた問題を記録し、正解するまで出題
- **きろく（保護者向け）**：日ごとの正解数・練習時間、モード別の正答率、データの書き出し・読み込み
- **せってい（保護者向け）**：音と声のオン・オフ、見本と解答の並べ方、リセット

## 仕組み

- `index.html` 1ファイルで動作（サーバー不要）。進み具合はブラウザの中（localStorage）に保存
- `sw.js` でオフラインでも起動できる
- 問題は毎回自動で作る。直前20問と同じ形は出さない。さかさ・かがみでは、反転しても形が変わらない図形は出さない
- 判定は「隣り合う点どうしを結ぶ短い線」の集まりで比べるので、線を引く順番や、長い線を1本で引いたか分けて引いたかは問わない

GitHub Pages（Settings → Pages → Branch: main / root）で公開。
